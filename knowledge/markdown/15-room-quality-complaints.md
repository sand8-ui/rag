# 客房品质投诉处理口径

文档编号：SW-SOP-ROOM-2026  
范围：脏、坏、吵、异味、与照片不符。不包含景观承诺（见北京酒店档案）和宠物（见 Docx）。

## 1. 先问清的五件事

1. 已办理入住了吗？房号？
2. 具体问题：一张照片能说明的，请用户描述位置（床、卫生间、空调、窗外）。
3. 是否已经和酒店管家/前台说过？对方什么态度？
4. 用户诉求：换房、清洁、部分退、全额退、今晚就走。
5. 是否涉及人身安全（漏电、玻璃碎、可疑人员）。安全优先，立刻转人工并让用户找酒店安保。

## 2. 分级

**A. 可现场解决（优先换房或补清洁）**

- 毛发、水渍、垃圾未清、缺少毛巾、马桶未冲、空调不制冷、电视无信号、台灯不亮、Wi‑Fi 连不上。
- 口径：请用户立即联系楼层管家；15 分钟无响应再让 StayWise 代催。一般不构成全额退。

**B. 需升级并可能补偿**

- 明显使用过的床单、卫生间严重污渍、异味无法开门窗缓解、持续施工噪声到 22:00 后、隔壁派对经酒店劝阻无效。
- 口径：记录时间线，建议换房；用户坚持离店按「已入住后退剩余晚」处理，是否免当天房费由工单定，禁止当场承诺免单。

**C. 卫生安全红线**

- 用户描述疑似虫患、霉菌大面积、污水倒灌、玻璃碎片划伤。
- 口径：建议换房或离店；拍照；必要时就医。StayWise 不在聊天里确认「一定是床虱」，转人工。

## 3. 「和照片不一样」

- 演示图来自图库，不是实时房号照片。话术：图片为房型示意，家具摆放、楼层、窗外会不同。
- 只有订单或详情页写了「保证江景 / 保证阳台」才按承诺处理。
- 面积主观感受（「好小」）不是违约。设计酒店（成都博舍）尤其要先降预期。

## 4. 噪声

- 外滩、太古里、王府井属商旅旺区，窗外人声、车声不视为设施故障。
- 走廊推车、隔壁说话：先请酒店协调换房。
- 宴会、婚礼、装修：问是否提前在订单备注或酒店告知。未告知且影响睡眠，可走补偿工单。

## 5. 禁语

- 「这类投诉我们不管，你找酒店。」
- 「我看了照片觉得还好。」
- 「那你今晚将就一下。」
- 编造「我已经给酒店打过分了」。
