# 代订、姓名不一致与证件问题

文档编号：SW-SOP-NAME-2026  
高频原话：「我帮领导订的」「证件和订单名字不一样」「英文名拼错了」。

## 1. 谁必须出现在前台

公安住宿登记要求：**实际睡在那张床上的人**必须出示本人证件。下单账号可以是助理、子女、同事。

- 订单邮箱是助理，入住人是领导：可以，领导带齐证件。
- 只有下单人的身份证、入住人不在场：多数酒店拒办。不能只拿别人身份证代办。
- 未成年人单独一间：见儿童政策，原则上不要鼓励。
- 多人分房：每间房的实际入住人都要登记，不能一张身份证开两间。
- 外籍护照须有有效入境章或居留许可，过期护照无法办理。

## 2. 姓名怎么才算一致

- 中文姓名与身份证完全一致，不要多「先生/女士」。
- 外籍：护照拼音与订单一致，顺序建议「名 姓」或与护照机读码一致。`ZHANG SAN` 与 `SAN ZHANG` 可能被前台拦。
- 生僻字、少数民族姓名：以证件芯片为准，客服把证件姓名发给酒店。
- 港澳居民来往内地通行证、台湾居民来往大陆通行证：号码与姓名都要一致。

演示系统**没有改姓名接口**。处理：

1. 若尚未入住且规则允许：删除旧单，用正确信息重订（演示价不变）。
2. 若不可取消或已过免费窗：转人工，请酒店备注「证件名 xxx，订单名 yyy」，不保证成功。
3. 不要让用户在证件上涂改。
4. 不要教用户改数据库快照字段。

签证确认函必须先姓名正确再出函，见签证文档。

## 3. 代订授权

酒店可能要求：

- 下单人电话能打通；或
- 手写授权「同意某某持本人证件入住」+ 下单人证件照片。

客服可提供授权书模板要点：双方姓名、订单号、入住日期、酒店名、签字日期。不代替法律意见。演示不能上传授权文件到订单，只能让用户自行携带纸质或手机照片到前台。

代订不是把房间转给不在证件上的人住。第三方平台买来的「确认号」若不是 StayWise 订单，不要在本系统里查。

## 4. 帮别人订错酒店/错城市

- 上海订成杭州：两家店都在演示清单里，只能删了重订。费用按取消规则。
- 「我以为外滩华尔道夫就是南京路那家经济型」：属于用户选店问题，不是系统把酒店换了。可以共情，按取消规则处理。
- 订错房型（大床 vs 套房）：不能改房型，只能删旧订新。
- 演示只有四城，用户要西安、三亚：明确没有，不要虚构可订酒店。

## 5. 离婚、改名、证件更新

用户改了身份证姓名：提供新旧证件，走人工。演示无法改历史订单快照上的用户邮箱。

结婚后改姓、护照换发后号码变化：同样走人工备注，不保证酒店系统接受。紧急当晚无法改证件的，建议本人到场说明并配合前台公安核验，客服不保证一定能住。

睡在床上的人必须本人证件到场。助理下单领导住可以。只拿下单人身份证代办多数拒。中文姓名不要加先生。护照拼音顺序不一致可能被拦。生僻字以芯片为准。无改名接口：未入住且规则允许则删了重订；不可取消过窗转人工备注不保证。禁止涂改证件与改数据库。授权书含双方姓名订单号日期酒店签字。订错城市按取消规则重订。改姓换护照走人工。签证函必须姓名先对。

姓名检索补充：实际入住人到场。ZHANG SAN 与 SAN ZHANG 可能被拦。无改名接口则删了重订或人工备注。授权书双方姓名订单号日期酒店签字。订错城市按取消规则。改姓换护照带新旧证走人工。签证函姓名必须先对。禁止涂改证件。不能一张身份证开两间。未成年人单独一间走儿童政策。港澳台通行证同样要一致。
