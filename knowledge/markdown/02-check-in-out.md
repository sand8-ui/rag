# StayWise 入住与离店须知

文档编号：SW-POL-CIO-2026  
适用酒店：演示环境四家签约酒店（上海外滩华尔道夫、杭州西溪悦榕庄、成都太古里博舍、北京王府井文华东方）。  
标准时间若与酒店现场牌示不一致，以现场牌示为准，并请客服记录差异。

## 1. 标准时间

| 项目 | 标准 | 说明 |
| --- | --- | --- |
| 入住 | 当日 15:00 以后 | 14:00–15:00 视空房尽量安排，不承诺 |
| 提前入住 | 12:00–14:00 | 可能收取首晚 30% 的提前入住费，或升级到已清洁房间 |
| 更早入住 | 12:00 以前 | 按「补订前一晚」处理，需有库存 |
| 离店 | 当日 12:00 以前 | 超时见第 3 节 |
| 行李寄存 | 入住日 08:00 起、退房后至 20:00 | 大件/贵重物品规则见安全文档（docx） |

## 2. 办理入住需要带什么

1. **订单确认信息**：StayWise 订单号或预订人手机号。
2. **入住人有效身份证件**：大陆居民身份证；港澳居民来往内地通行证；台湾居民来往大陆通行证；外籍护照及入境章/居留许可。
3. **本人到场**：公安实名要求，不能只拿别人身份证代办。未成年人入住须监护人陪同并登记。
4. **押金或预授权**：现金或信用卡预授权，额度一般为 **500–2000 元/间**，用于迷你吧、损坏、超时退房。离店查房后退还，信用卡预授权解除通常 1–15 个工作日，以发卡行准。

平台预付订单：房费已付给 StayWise，前台一般只收押金，不再收房费。若前台要求再付一遍房费，请用户立即在 App 打开订单给前台核对「预付」标记，并联系在线客服。

## 3. 超时退房（Late Check-out）

| 离店时间 | 费用 |
| --- | --- |
| 12:00–14:00 | 免费或视房态；客服可先帮问酒店 |
| 14:00–18:00 | 通常收取半晚房费 |
| 18:00 以后 | 通常收取全晚房费 |

申请建议：入住当天或前一晚在 StayWise 订单点「改期」不能代替超时退房申请。超时退房要走客服工单或酒店前台，**不改变离店日期字段**。

## 4. 未到店（No-Show）

- 入住日 18:00 前仍未办理且未取消，酒店可将房间释放给当天 Walk-in。
- 费用按取消政策中的 No-Show 档执行。
- 晚到且希望留房：请在 18:00 前致电酒店或找 StayWise 客服做「晚到担保」，否则不保证留房。

## 5. 加床、加人、访客

- 房型「最多 N 人」含儿童。超过容量必须换更大房型或加订一间。
- 演示环境：江景豪华大床房最多 2 人，行政套房 3 人，湿地别墅 2 人，家庭套房 4 人，城市景观房 2 人，禅意套房 2 人，豪华客房 2 人，紫禁城景观套房 3 人。
- 日间访客一般可至 22:00，过夜访客必须前台加登记并可能加收。

## 6. 城市差异备忘

- **上海外滩**：部分历史建筑房间较难提前入住，因清洁动线长。
- **杭州西溪**：别墅类房间布草较多，15:00 前成功率低于城区酒店。
- **成都博舍**：节假日太古里交通拥堵，建议预留出行李时间。
- **北京王府井**：大型活动日安检升级，入住排队可能超过 30 分钟。
