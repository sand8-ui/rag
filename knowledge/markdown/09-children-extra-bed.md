# 儿童、婴儿与加床政策

文档编号：SW-POL-CHILD-2026

## 1. 年龄定义

- 婴儿：0–2 周岁（不含 3 周岁生日当天）。
- 儿童：3–11 周岁。
- 12 周岁及以上按成人计入房型人数。

## 2. 是否占用人数

- 婴儿不占用房型「最多 N 人」，但每间最多 1 名婴儿，且必须有成人同住。
- 儿童占用人数。例如家庭套房最多 4 人，可以是 2 成人 + 2 儿童，不能是 2 成人 + 3 儿童。
- 演示下单会校验 `guests` 与 `capacity`。用户填 3 人去订最多 2 人的大床房，前端禁用、后端 400。

## 3. 加床与婴儿床

- 加床：视酒店供应，通常 150–400 元/晚，现场付。大床房往往无法加床。
- 婴儿床：免费或低价，数量少，需提前 24 小时申请。
- 沙发床是否算正式床：行政套房第三人通常睡沙发床，客服应说明「不是独立卧室」。

## 4. 早餐与门票

- 儿童早餐是否免费以酒店当日规则为准，演示不默认免费。
- 景区儿童票与酒店无关。

## 5. 安全

- 泳池必须成人陪同。
- 窗锁、阳台门：别墅与江景房提醒不要让儿童单独留在阳台。
- StayWise 不提供儿童看护服务。
