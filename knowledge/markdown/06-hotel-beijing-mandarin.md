# 酒店档案：北京王府井文华东方

酒店 ID：`hotel-4`  
地址：北京市东城区王府井大街 1 号  
演示评分：4.9  
演示房价：豪华客房 2100 元/晚（2 人），紫禁城景观套房 5600 元/晚（3 人）

## 1. 位置

王府井步行街北段，东侧紫禁城方向。适合观光（故宫、景山、王府井教堂、北京饭店一带）与政务商务。大型活动、两会、节庆期间周边安检与交通管制频繁。

## 2. 交通

- 地铁 1 号线王府井站，或 5 号线东四 / 灯市口再步行。
- 首都机场：机场线 + 地铁，或出租车 40–80 分钟。
- 大兴机场更远，通常 70–110 分钟。
- 北京站较近，北京西 / 北京南需地铁换乘 40–60 分钟。
- **管制日**：长安街沿线可能临时封路，导航会绕行，不算酒店未履约。

## 3. 房型

### 豪华客房（room-4-1）

- 城市景观或内院景观，2 人。
- 不要默认承诺「看得见故宫」。

### 紫禁城景观套房（room-4-2）

- 高价产品，部分角度可见故宫方向屋脊或筒子河一带，受楼层、树冠、天气、雾霾影响。
- 最多 3 人。
- 若用户以「完全看不到故宫」为由要求全额退：先核实房型名称是否含「紫禁城景观」；能证明完全无相关景观的，可走升级或部分补偿工单，**不直接承诺全额退**，除非订单条款写明「景观保证」。

## 4. 参观故宫的实用提示（客服常被问）

- 故宫需提前在官方渠道预约，酒店不能代买门票。
- 建议早出入场。行李不能带进故宫，可用酒店当日寄存。
- 冬春大风天在城墙附近体感温差大。

## 5. 安保与证件

- 前台严格执行实名。外籍客人护照信息须与订单姓名拼音一致，否则可能无法入住，需改订单姓名（免费，须本人证件）。
- 访客登记比南方城市更严，过夜访客必须加登记。
