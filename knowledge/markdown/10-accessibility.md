# 无障碍与特殊需求指引

文档编号：SW-POL-A11Y-2026  
原则：如实说明限制，不承诺「一定有无障碍房」。申请成功与否以酒店书面回复为准，StayWise 不能在演示里锁定房号。

## 1. 四家演示酒店概况

| 酒店 | 无障碍友好度 | 说明 |
| --- | --- | --- |
| 上海外滩华尔道夫 | 低 | 历史保护建筑，电梯与卫生间改造受限 |
| 杭州西溪悦榕庄 | 中低 | 别墅台阶、木栈道、接驳距离长 |
| 成都太古里博舍 | 中 | 商圈较新，仍需确认房间编号 |
| 北京王府井文华东方 | 中高 | 城市豪华酒店，申请成功率相对高 |

外滩店常见限制：电梯轿厢小、部分楼层无无障碍淋浴、走廊曲折。不要说「五星级一定有无障碍房」。西溪店别墅庭院台阶、雨天木栈道对轮椅不友好，接驳距离长，即使用家庭套房也不等于无障碍套房。

用户已下单再问无障碍：立刻开工单向酒店申请，同时说明可能无法换到指定房、可能需要改期或取消（按取消政策）。不要让用户「先住一晚再看」。

## 2. 可申请项目

- 低位门镜、卫生间扶手、滚筒淋浴、振动手表消防提示
- 冰箱用于胰岛素（不是医用冷链，温度不保证）
- 安静楼层、远离电梯
- 轮椅可达餐厅（不是所有餐厅都有坡道）
- 一楼或近电梯房、加长床（视库存，不承诺）
- 书面逃生路线、可视化门铃（视酒店设备）

申请应在入住前至少 48 小时通过客服工单提交。当天到店再提，成功率明显下降。工单要写清：行动方式（轮椅/拐杖/视觉/听力）、是否需滚筒淋浴、是否有陪同者。成功与否以酒店书面回复为准。

演示没有「无障碍」筛选器。客服不要在 SSE 里假装已经改好房号。

## 3. 服务犬

导盲犬、扶助犬按国家规定允许进入公共区域。其他宠物见 Docx《宠物与过敏》。服务犬仍建议提前告知，便于安排一楼或近电梯房。

需准备：证件、犬只标识、疫苗本（酒店可能查）。服务犬不是伴侣宠物，不要收「宠物清洁费」口径；若酒店错误收费，转人工协调。禁止让用户「把犬只装包混入」外滩店。

## 4. 过敏

- 乳胶枕头、羽绒被可申请替换，不保证 100% 无致敏原。
- 客房清洁使用通用清洁剂，无法承诺「无香精房」。
- 即使某店禁宠，历史房间仍可能有毛发残留。严重过敏请在工单写「需无宠楼层」，不保证绝对无毛。
- 严重过敏应建议用户自行携带用品并咨询医生，客服不做医疗建议，不推荐具体药品。
- 花生、海鲜等餐饮禁忌可转达厨房，不保证独立厨房或零交叉污染。

外滩历史建筑电梯小、无障碍淋浴少。西溪台阶木栈道接驳长。博舍较新仍要确认房号。王府井相对好申请。当天到店再提成功率低。胰岛素冰箱不是医用冷链。不承诺无香精房、无致敏原、无宠残留为零。服务犬允许公共区域，建议提前告知，不要收宠物清洁费口径；禁止装包混入。陪同者人数仍受房型容量限制。演示无无障碍筛选，不能假装改好房号。书面回复前不要保证「一定安排一楼」。

无障碍检索补充：不承诺一定有房。外滩低、西溪中低、成都中、北京中高。48 小时工单写清轮椅淋浴听力视力陪同。胰岛素冰箱非冷链。无香精无绝对无毛不保证。服务犬合法进入须提前告知，禁止装包混入外滩。当天申请成功率低。演示无筛选器。成功以酒店书面为准。行动不便叠加电梯全停要升级人工考虑离店。
