# 扩展酒店与周边（客服会问「还有别的店吗」）

文档编号：SW-MOCK-HOTEL-EXT-2026  
演示可订的只有 4 家。下面是**知识库里的周边对照**，方便回答「附近还有什么」，并说明**不能在 App 里下单**。

## 1. 上海外滩一带（不可订，仅介绍）

**外滩源里的精品店（虚构档案 SW-SH-A）**  
定位：小体量设计酒店，房间少、夜间安静。价格心理区间 1600–2400。无江景保证。适合嫌华尔道夫太大的人。StayWise 未签约。

**南京东路商务酒店（虚构档案 SW-SH-B）**  
地铁口，房间偏小，隔音一般。价格心理区间 700–1100。适合纯睡觉赶高铁。不推荐蜜月。

当用户只要「便宜一张床」时，可以介绍这类定位，并明确：**请到其他平台搜索，StayWise 演示下不了。**

## 2. 杭州西湖 vs 西溪

用户订了西溪却天天跑西湖：每天单程可能超过 40 分钟。若行程以西湖、灵隐为主，应在下单前告知「西溪是湿地度假，不是湖滨步行」。  
西湖边（虚构 SW-HZ-A）：观光方便、周末噪声大、停车难。  
西溪悦榕庄：静、贵、交通弱。

## 3. 成都春熙 vs 宽窄

博舍在太古里。用户想住宽窄巷子：车程视拥堵 20–40 分钟。  
宽窄附近虚构经济型 SW-CD-A：小吃近、房间一般。  
博舍：购物方便、设计感、房间不一定大。

## 4. 北京王府井 vs 国贸 vs 后海

- 王府井文华东方：观光与步行街。
- 国贸（虚构 SW-BJ-A）：商务、CBD，去故宫更远。
- 后海（虚构 SW-BJ-B）：酒吧街噪声，不适合带老人除非明确要夜生活。

用户订王府井却每天去国贸开会：建议评估通勤 40–70 分钟，是否值得改订（演示不能改酒店，只能删了重订——但没有国贸店可订，只能提示限制）。

## 5. 虚构房型词典（防幻觉）

以下 ID **不存在于下单系统**，模型不得当成可订房型：

- room-x-1、room-99、总统套房、无边泳池别墅（四家店都没有无边泳池卖点，杭州是湿地不是海）。

可订 ID 只有：room-1-1、room-1-2、room-2-1、room-2-2、room-3-1、room-3-2、room-4-1、room-4-2。

介绍周边时必须口头声明「StayWise 演示下不了单」。用户只要便宜一张床：可介绍南京东路商务型定位（心理价 700–1100），并送去其他平台。嫌华尔道夫太大：可介绍外滩源精品定位（1600–2400 心理价），无江景保证。西湖行程不要推荐西溪当湖滨酒店。宽窄行程不要把博舍说成住在巷子口。国贸开会不要假装能改订国贸店。

虚构档案编号 SW-SH-A/B、SW-HZ-A、SW-CD-A、SW-BJ-A/B 仅知识库对照，禁止当成可订。总统套房、无边泳池别墅不存在。四家店都没有海边无边泳池卖点。

可订只有四家。周边介绍必须声明演示下不了单。外滩源精品心理价 1600–2400 无江景保证。南京东路商务 700–1100 隔音一般。西湖边噪声停车难，西溪静但交通弱。宽窄与太古里 20–40 分钟。国贸商务去故宫更远，后海酒吧噪声。虚构 ID 禁止下单。room-x-1、room-99、总统套房、无边泳池别墅都不存在。可订仅 room-1-1 到 room-4-2。用户要西安三亚直接说没有。

周边检索补充：可订仅四家八个房型 ID。介绍未签约店必须说演示下不了。SW-SH-A/B、SW-HZ-A、SW-CD-A、SW-BJ-A/B 是虚构对照。总统套房无边泳池别墅不存在。西溪不是湖滨。博舍不是宽窄口。王府井不是国贸不是后海。要西安三亚直接说没有。便宜床可介绍南京东路商务定位并送其他平台。改酒店只能删了重订且清单仍只有四家。
