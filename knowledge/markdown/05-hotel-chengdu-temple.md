# 酒店档案：成都太古里博舍

酒店 ID：`hotel-3`  
地址：成都市锦江区中纱帽街 81 号  
演示评分：4.6  
演示房价：城市景观房 1280 元/晚（2 人），禅意套房 2180 元/晚（2 人）

## 1. 位置

酒店毗邻大慈寺与成都远洋太古里，步行可至春熙路商圈。适合购物、美食、短途商务。房间偏设计风，部分房间面积小于国际连锁行政楼层的平均预期，需管理「设计酒店 ≠ 一定很大」。

## 2. 交通

- 地铁 2/3 号线春熙路站，步行约 8–12 分钟。
- 成都双流机场：地铁 + 换乘约 50–70 分钟；出租车 40–70 分钟。
- 天府机场更远，出租车常 70–100 分钟，建议预留。
- 太古里步行区周末人流大，网约车停靠点可能在周边路口，按酒店短信「上车点」走。

## 3. 房型

### 城市景观房（room-3-1）

- 城市或街区景观，非雪山景观。
- 2 人入住。窗可能朝向内街，夜间有商业区轻噪声，属地段特征。

### 禅意套房（room-3-2）

- 空间更大，装饰强调安静与材质，仍是 2 人上限。
- 适合想在购物区找「安静房间」的客人，但不能承诺「完全无噪声」。

## 4. 餐饮与周边

- 太古里、中山广场、大慈寺素斋、春熙路小吃步行可达。
- 火锅、串串气味重，提醒客人勿在房间煮食，烟雾报警会响。
- 酒店早餐若含在房价中，以订单「含早」字段为准；演示数据房价默认 **不含早**，客服不要随口说含早。

## 5. 本地习惯

- 下午茶、夜市节奏晚，23:00 后仍热闹。
- 冬季潮湿阴冷，房间供暖以空调为主，体感因人而异。
- 熊猫基地不在步行范围，需约 1 小时车程，酒店不包含门票。
